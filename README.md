## About this repository

This repository contains **only the compiled website and its public assets**, published for GitHub Pages.

The original React and TypeScript source files, development configuration, dependencies, and source-code Git history are not included. Compiled JavaScript and CSS are public because browsers need them to display the site.

## Hosting

GitHub Pages serves the contents of the **main** branch from the repository root. The **.nojekyll** file allows the prebuilt assets to be served directly.

No installation or build step is required in this repository. Website updates are built separately and published here as compiled files.
